# 语音输入与对话等待

- 将 main 上 girthrd 的 PR #12 (e7ea0467) 真正合入 feat/agent-native-product（合并提交 12c5c53）。保留此前 Agent、三端门户、行程及附件功能。
- Web 使用浏览器 SpeechRecognition；移动 Web 同样调用浏览器识别。Android 使用系统 ACTION_RECOGNIZE_SPEECH，由系统服务提供中文语音转文字；没有系统识别器时提示使用输入法。识别结果追加到当前输入，不自动发送、不上传到本项目的对话服务。
- Windows WebView2 / macOS WKWebView 暂无自建录音识别桥接，支持系统语音键入/听写；不声称原生麦克风已完全打通。若使用浏览器识别，实际提供方、语言包及联网需求由浏览器或系统决定。真实麦克风、权限弹窗及识别准确性需要真机验收。
- 等待指示为实际请求状态下的轨道旋转及文字微光，不假装执行隐藏推理流程，也不声称开启深度推理模式。响应、取消、失败后结束；支持 prefers-reduced-motion。
- 浏览器回归采用隔离模拟识别回调与 HTTP 请求，用于验证识别文本保留、手动发送、加载指示、取消与恢复，不等同实测语音识别。
