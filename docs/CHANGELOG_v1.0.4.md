# 吉政知行 1.0.4

## 多轮旅行对话恢复

- 恢复吉小知连续对话界面，消息流与行程结果卡片共存。
- 支持在同一会话中连续补充、修改目的地、天数、季节、同行人、兴趣和排除条件。
- 客户端在本机保存最近一段会话与当前行程，不保存联网访问码；提供“新对话”清除当前会话。
- 联网请求向 `/api/travel` 发送有界历史和上轮结构化意图；服务端校验上下文后再执行检索、编排与复核。
- 离线规划保留本地约束上下文；原有行程保存、分享、朗读、路线发现、工作台和语音输入继续保留。
- Android 版本号升级至 1.0.4，预览 APK 由 GitHub Actions 构建。

## 验证范围

- `npm run build:mobile`
- `npm test`
- Android APK 构建、签名与 badging 检查
- 手机宽度 320 / 390 / 430 / 820 px 的浏览器流程回归
- 连续两轮请求携带上一轮历史和结构化约束
