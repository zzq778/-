# 吉政知行 0.9.7 · 移动产品重构

范围：独立移动 Worker `mobile/site`、Android 壳、移动 API 与共享文旅行程文案；原 `public/` 旧站及独立游客/商户/管理入口不在本次发布范围，保留队友工程。

- 使用单一 CSS 视觉系统，移除光球、星芒、过度渐变、英文装饰文字、研发术语、用户可见工具日志；保留 12 张完整透明主题插画，未声称实拍。
- 首页主任务精简，设置按需展开；发现页筛选与路线详情独立。行程建议仅在成功联网、内容适宜时按需展示；离线与资料规划状态真实区分。后端真实工具调用及 trace 未移除。
- 本地角色模拟替换为可用的旅途记录，明确不向政府或商家提交；保留旧本机记录及备注。多行程收藏支持旧单项迁移、去重、最多 20 份及确认删除。大字设置持久化。访问码不保存。真机无语音支持时不显示不可用入口。
- 真实等待状态、取消等待、网络/限流/访问码/降级/追问；取消等待不承诺停止已经送达服务器的推理。Android 系统返回交由前端页面层级处理。统一版本号，去除不用的 orb 资源。
- 本地 Chromium：320/390/430/820 CSS px 全部通过实际渲染与核心交互；390 px 额外覆盖认证缺失/错误、网络、限流、降级、取消和补充条件。利用注入的 mock HTTP 响应和存储验证，不是假称真实云推理。
- 分支隔离：`feat/wenlv-product-v097`；正式线上仍保留 0.9.6，未经完整回归、实体手机检查及发布确认不切换。
- 产品边界：知识库不是实时地图、交通、预约或票务接口；本机记录不是多角色联网协同。所有实地信息需查阅官方来源。APK 仍为临时测试签名，旧版覆盖安装不一定成功。
