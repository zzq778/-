# 文旅知识库 · 数据源清单（D1 / A 线交付）

本文件回答两个问题：**事实从哪来**、**凭什么相信它**。所有进入知识库的条目都必须能在这里找到对应来源，并带上核对日期。

## 一、引用原则

1. **只引官方**：政府门户、文旅主管部门、景区运营主体的官网或官方公众号。攻略站、点评、短视频、博客一律不作为事实来源。
2. **可回溯**：每条数据记 `sources`（来源标签 + URL + 类型）与 `verifiedAt`（核对日期），评委现场可以点开看。
3. **不确定就留空**：票价、开放时间、实时客流这类会变的字段，没核对到官方口径就写 `null`，界面显示"以官方为准"，**不写"约""大概""预计"这类模糊数字**。
4. **不搬运**：只引用链接和事实性短句，不整段转载政策原文、不搬运图片（版权归原权利人）。
5. **时效**：`verifiedAt` 超过 30 天要复核；复核记录写进 `docs/CHANGELOG` 或条目内的 `caveat`。

## 四、采集与复核流程

```
选题（覆盖哪些市州/主题）
  → 打开官方页面截取事实（标题/发布机关/日期）
  → 写入数据文件：sources + verifiedAt + confidence
  → 跑 node tests/wenlv_data.test.mjs（结构、域名白名单、空值规则）
  → 30 天后复核，过期条目在 caveat 标注"待复核"
```

- `confidence`：`high` = 政府/景区官网明文；`medium` = 官方公众号或政府转载；`low` = 仅二手印证，**低置信条目不得直接用于生成结论**。
- 同一事实出现两个官方口径不一致时，取发布层级更高的那个，并在 `caveat` 里写明。

## 五、合规红线（对应评分表 2.3 规范性）

- **地图**：不自绘省界、国界、九段线。需要图示时用标准地图服务底图并标注审图号，或用纯文字节点列表代替地图。
- **票价/时间**：不得编造，不得把往年价格当今年价格。
- **图片**：不使用景区图库、社交平台图片；需要配图时用自制插画或取得授权的素材。
- **隐私**：行程规划只收集人数、天数、偏好，不收集身份证、手机号、住址。
- **表述**：应用是参赛作品，不是政府官方软件；解读类文字标注"由参赛项目组撰写，不是官方解释"。

## 六、禁止来源（写进评审材料，用来说明边界）

小红书 / 抖音 / 微博 / 携程与美团的点评与问答 / 个人博客 / 未标注出处的聚合攻略 / AI 生成的"旅游攻略"文本。

理由：不可回溯、无发布主体、内容常含过时票价与错误位置，一旦被引用就是幻觉放大器。
