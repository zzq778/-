# 统一产品主线

基线：feat/wenlv-product-v097。main 与其他同学分支均为其祖先，无需重复合并。

- 移动端保留旅行规划、路线、行程收藏以及个人旅途记录；从旅途记录进入游客、商户和管理工作台。
- 工作台统一复用 public/portals 的渲染、数据与规则。npm run build:mobile 生成移动资源；移动 Worker 构建和 Android 打包自动执行。直接使用静态开发服务器之前也须运行一次构建。
- 三端仅共享本机同源存储，无真实身份认证、正式审批或跨设备同步；各部署域名的既有本地存储不会自动迁移。
- 发布门槛：全量 Node 回归、移动浏览器流程、三端跨角色浏览器流程、Web 回归和真机核对。未通过不得更新 main 或生产部署。
