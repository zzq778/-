# 吉林文旅助手 · 首发候选 v0.8.0

## 产品定位
吉林特色文旅旅行 Agent。面向游客，优先帮助提出需求、形成可执行的候选行程、理解安排理由、核对资料和继续准备。商户/管理端提供本机协同演示；原政务导办降为便民工具，不删除既有模块。

## 实际路径
- 首页自然语言或浏览器支持时的语音输入；目的地区、1–3 天、同行人和季节为可选条件。
- POST /api/chat（mode=wenlv）调用原有意图解析、检索、编排、可选模型表述及规则校验。
- 展示服务端返回的真实规划摘要、分天行程、知识库来源与核对日期；不把规划过程当作模型隐藏思考。
- 在明确指定地区内选景点；识别知识库中有限的明确排除词及景点，拒绝含排除对象的线路模板。节点不足留空，不跨市凑数。无匹配返回说明且不调用模型。
- 本机保存只含天数、景点 ID 与时段槽位；可恢复、删除、朗读、分享文本。接口失败不丢弃上次有效计划。
- 12 条精选线路无需云模型即可查看。三端沿用队友的现有门户和本地数据层，明确不连接真实商户及政府后台。
- 统一松石绿 / 雾白 / 暖金首页与三端界面；原创 CSS/SVG 山水意象，不冒充景区照片。
