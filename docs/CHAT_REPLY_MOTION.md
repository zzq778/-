# 渐进式回复显示

回复仍由原有已验证的 JSON Agent 接口一次返回。客户端对最终文本按中文词组及 Unicode 字符分段，采用有节奏的渐进显示（并非网络端真实 tokenizer 或 SSE 流式推理）。标点短暂停顿、最近文本轻微淡入、末端呼吸光标，长回复显示时间自适应，随时可显示全文。原始完整文本在历史中保持不变。移动端等待图标只在请求未完成时展示，回复到达后不主动弹起手机键盘；切换页面、后台、发送下一问与新对话时结束动画。系统减少动态效果及大字模式直接展示完整回复。Android / Windows / macOS 共享移动网页实现，Web 独立页面沿用相同调度。无服务端接口改动。
